## 🌐 À propos de Coinly Extension

**Coinly Extension** est l'extension officielle de **Coinly**, le convertisseur universel pensé pour rendre les conversions simples, rapides et accessibles.

Grâce à l'extension, vous pouvez accéder aux outils de conversion de Coinly directement depuis votre navigateur, sans avoir besoin d'ouvrir le site à chaque fois.

L'objectif est simple : **convertir ce dont vous avez besoin en quelques secondes**.

---

## ✨ Fonctionnalités

- ⚡ Accès rapide aux conversions depuis le navigateur
- 💱 Conversion de devises

## 🚀 Installation

### Installation manuelle

1. Téléchargez ou clonez ce dépôt :

```bash
git clone https://github.com/Leo0957/Coinly-Extension.git
```

2. Ouvrez la page de gestion des extensions de votre navigateur.

3. Activez le **mode développeur**.

4. Cliquez sur **Charger l'extension non empaquetée**.

5. Sélectionnez le dossier contenant Coinly Extension.

L'extension devrait maintenant apparaître dans votre navigateur.

---

## 🖥️ Utilisation

Une fois l'extension installée :

1. Cliquez sur l'icône **Coinly** dans la barre d'extensions.
2. Choisissez le type de conversion souhaité.
3. Entrez votre valeur.
4. Obtenez instantanément le résultat.
